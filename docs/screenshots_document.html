Public Access & Authentication

Pages accessible without login — Login, Public Gallery

PUBLIC

Login Page

Secure email + password authentication gateway. On success the system validates role, account status, and lock state — then redirects each user to their role-specific dashboard. Login IP address and timestamp are tracked on every session.

Public Gallery

Publicly accessible showcase of all published institutional activities. Browse with full-text search, category filter, college filter, and date-range filter. Responsive image grid links to individual activity detail pages.

👑 Super Admin — Enterprise Control Panel

superadmin@vmrfdu.edu.in · Role: super_admin · Unrestricted access to all system functions

SUPER ADMIN

Super Admin Dashboard

System-wide enterprise overview: total activities, users, colleges, workflow status, pending actions across all roles, recent activity feed, and quick-access navigation to every admin module.

04 / 42
📊 System-Wide KPIs👥 Users & Colleges🔄 Workflow Status⚡ Quick Actions
SUPER ADMIN

College Management

Full CRUD for all constituent colleges. Create with unique codes (e.g., VMKVEC), set location, dean name, contact email, website. Toggle active/inactive status. All college assignments across users link back to these records.

05 / 42
➕ Create College✏️ Edit🔘 Active Toggle🏫 College Code
SUPER ADMIN

User Management

Create and manage all portal user accounts. Assign roles (super_admin, registrar, vc, office_registrar, media_editor, college_admin, department_user), link to colleges, set designation, force password reset, lock/unlock, transfer between colleges.

06 / 42
➕ Create User🎭 Role Assign🔒 Lock/Unlock🔑 Force Reset🏫 College Transfer
SUPER ADMIN

Role & Permission Builder

Create dynamic roles with JSON permission matrices. Assign data scopes (global or college-scoped). Configure permissions for each module: colleges, users, activities, approvals, media, analytics, settings, roles, audits.

07 / 42
🎭 Role Definitions🔑 JSON Permissions🌐 Data Scope⚙️ Overrides
SUPER ADMIN

Workflow Engine Configuration

Create, edit, and duplicate approval workflow templates. Configure each stage: name, order, required role, allowed actions (approve/discuss/reject), status transitions on each action. Set routing rules by category, college, or activity type.

08 / 42
🔄 Multi-Stage Workflow⚙️ Stage Config📋 Action Mapping🌿 Templates
SUPER ADMIN

Enterprise Access Control Suite

Per-user permission overrides beyond role defaults. Copy a role's full permission set to multiple users simultaneously. View and manage the complete cross-role permission matrix.

09 / 42
🔑 Per-User Override📋 Copy Role🎭 Full Matrix
SUPER ADMIN

Unrestricted Activity Management

Override view of all activities across all colleges and all stages. Force status changes, reassign ownership, restore soft-deleted records, and perform hard deletes. Full administrative control without workflow restrictions.

10 / 42
⚡ Force Status♻️ Restore👤 Reassign🗑️ Hard Delete
SUPER ADMIN

System Audit Logs

Immutable system-wide audit trail. Every critical action logged with: acting user, action type, affected record ID, before/after values, IP address, and precise timestamp. Cannot be edited or deleted.

11 / 42
📜 Immutable Records👤 User + IP🔍 Before/After📅 Timestamp

Master Settings & Branding

Portal-wide configuration: upload university logo and favicon, set default user avatar, configure NTP time synchronization, manage session lifetime. Controls the visual identity and core behaviour of the entire portal.

12 / 42
🖼️ Logo & Favicon🕐 NTP Sync⏱️ Session Config🎨 Branding

Analytics Dashboard (Super Admin)

University-wide KPI dashboard with cross-college data visibility. Charts: activities by category, by college, by approval stage, by month. Export options: CSV download and printable executive report with branding.

13 / 42
📊 University-Wide KPIs📈 Trend Charts📥 CSV Export🖨️ Print Report

Notification inbox with read/unread status tracking. Mark individual or all-as-read. Each notification links to the relevant activity, approval, or system event.

MEDIA EDITOR

Media Editor Dashboard

The Media Editor's command centre — lands directly on the Media Studio. Displays queue counts: editing queue (media_review), locked submissions pending Stage 2 (registrar_approval 🔒), revision queue (editor_discuss 🔓), and ready-to-publish.

31 / 42
📸 Editing Queue🔒 Locked Count✅ Ready Count🔓 Discuss Queue
MEDIA EDITOR

Media Studio — Editing Queue & Locked Submissions

All activities in media_review status appear in the editing queue for photo optimization and caption refinement. After submitting to the Office of Registrar, records move to the Locked section (🔒 read-only padlock) until Stage 2 is resolved. Activities in editor_discuss are returned for revision.

Create New Activity Form

The primary submission form. Fields: title, description, event date, category (Symposium / Workshop / Health Camp / Guest Lecture / Cultural / MoU / NSS / etc.), location, target audience, faculty coordinator details, social media caption. Mandatory photo upload (JPG/PNG/WEBP, max 10 MB), optional PDF upload (max 15 MB). Integrated AI Caption Generator modal with 12+ professional templates. Save as Draft or Submit directly.
