SLIDE 02 / 17
The Challenge
Problem Statement

VMRF(DU) conducts hundreds of institutional activities across its constituent colleges every year. Managing this at scale was fragmented and error-prone.

📧

Fragmented Communication

Activity records scattered across emails, WhatsApp groups, and shared drives. No single source of truth.

❌

No Approval Structure

No standardized multi-stage approval workflow. Approvals happened informally without audit trails.

🖼️

Inconsistent Media Quality

Photos published without optimization. Social media captions were inconsistent and unprofessional.

📉

No Analytics or Visibility

Management had no visibility into activity volumes, approval rates, or publication status.

SLIDE 03 / 17
Our Answer
The Solution

A unified, enterprise-grade web portal that centralizes every step — from activity submission to social media broadcast — with full audit, approval, and quality control.

📋

Centralized Submission

College admins submit activities with structured data and mandatory media. Unique reference IDs auto-generated.

✅

Multi-Stage Approval

Structured workflow: College Admin → Registrar → Media Editor → Office of Registrar → Publish.

🎨

AI Media Studio

AI caption generation with 12+ templates. Professional media packs ready for multi-platform publishing.

📡

Multi-Platform Broadcast

One-click publishing to Instagram, LinkedIn, Twitter/X and the public institutional gallery.

📊

Analytics & Reports

Real-time KPI dashboards, role-scoped data views, and CSV/print export for management reporting.

🔒

Complete Audit Trail

Immutable approval logs, email audit trail, and system audit for full governance and compliance.

End-to-End Process
Activity Approval Workflow

A structured 4-stage pipeline ensures quality, authenticity, and professional presentation before any activity is publicly broadcast.

🏫
Stage 1
College Admin
Submit Activity
→
🏛️
Stage 2
Registrar
Verify & Approve
→
🎨
Stage 3
Media Editor
Optimize + Pack
→
📋
Stage 4
Office of Registrar
Final Approval
→
🎉
Published
Multi-Platform
Public + Social

🔒 Status Locking: When the Media Editor submits for Stage 4 review, the record is automatically locked (read-only). This prevents concurrent modifications during the Office of Registrar's executive review. Only the Office of Registrar can unlock it by sending for discussion.

↩ Discuss (Stage 1)

Returned to College Admin for corrections. Activity unlocked for editing.

↩ Discuss (Stage 2)

Record unlocked and returned to Media Editor queue for revision.

❌ Reject (Stage 1)

Terminal state. Activity closed with mandatory remarks.

SLIDE 09 / 17
Technical Design
System Architecture

⚙️ MVC Architecture (Laravel 12)

14 Controllers · 17 Eloquent Models · 33 Blade Views · Route-level RBAC middleware · Service layer for AI phrasing

🗄️ Database Layer (MySQL 8.0)

16+ tables with strict FK constraints · Soft deletes on critical tables · JSON columns for permissions & tags · Database-backed sessions, cache, & queue

🔄 Workflow Engine

Configurable stage-based state machine · Dynamic routing by category/college · Status transition validation · User or role-based stage assignment

🎨 Frontend (Bootstrap 5.3)

Responsive layout · Blade component system · AI modal with template library · Dynamic status badge renderer · Chart.js KPI dashboards · Role-scoped navigation

🔒 Status Locking Engine

Automated record locking on Stage 2 submission · Visual padlock indicator 🔒 · Atomic unlock on discussion action · Concurrent edit prevention

📡 Output & Integration

ZIP media pack streaming · Multi-platform publishing record · CSV & print report export · SMTP email with queue driver

Unique Capability
AI Caption Generation Engine

Every activity submission and media editing session includes an integrated AI-powered caption generator that produces professional, on-brand social media content instantly.

📝

12+ Professional Templates

Templates covering Symposiums, Workshops, Health Camps, Guest Lectures, Sports Events, Cultural Events, Faculty Development, and more.

⚡

Dynamic Context Injection

Auto-fills event title, college name, event date, and category into the template. Zero manual editing required for the basic caption.

#️⃣

Hashtag Generation

Automatically appends relevant institutional hashtags (#VMRFDU, category tags) to every generated caption for maximum social reach.

🎯

Multiple Tone Options

Templates range from formal institutional to celebratory, community-focused, and informative — covering all communication styles.

✏️

Editable Output

Generated captions are fully editable. Users can refine the AI output before saving to the submission record.

🔄

Reusable at Every Stage

Caption modal available during initial submission AND during media editing stage for further refinement.

SLIDE 13 / 17
Protection & Governance
Security Architecture
🛡️

CSRF Protection

Laravel's built-in CSRF middleware with @csrf tokens on every form.

🔐

Password Security

Bcrypt hashing. Force-reset on first login. Password strength enforcement.

🚫

Authorization Checks

abort_if() on every controller method. 403 pages for unauthorized access.

🗂️

Data Isolation

College-scoped and department-scoped database queries. Cross-college data leakage prevented.

📁

File Validation

MIME type whitelist + size limits on all uploads. Only approved file formats accepted.

🔒

Status Locking

Records locked during executive review to prevent concurrent modification conflicts.

📜

Immutable Audit Trail

Every approval action logged with user, IP, timestamp, before/after values.

🌐

Session Security

Database sessions. 120-min inactivity timeout. Encrypted session cookies.
