SYSTEM ARCHITECTURE

⚙️ Backend (Laravel 12 / PHP 8.2+)

  • MVC Architecture with Eloquent ORM
  • 14 Controllers | 17 Models
  • Blade Templating Engine (33 Views)
  • RBAC Middleware Stack
  • Multi-stage Workflow Engine
  • Status Locking Mechanism
  • AI Phrasing Service (12+ templates)
  • Queue Driver (Database)

🗄️ Database (MySQL 8.0)

  • activity_submissions (core records)
  • activity_media (photos, docs, videos)
  • activity_discussions (feedback threads)
  • approval_logs (immutable audit trail)
  • users + colleges + roles
  • workflows + workflow_stages + rules
  • portal_notifications + email_logs
  • published_posts + system_audit_logs

🎨 Frontend (Bootstrap 5.3)

  • Bootstrap 5.3 Responsive Grid
  • Blade Component System
  • AI Modal with Template Library
  • Dynamic Status Badge Renderer
  • Role-scoped Navigation
  • Chart.js Analytics Dashboards
  • File Upload with Preview
  • Printable Report Views

📡 Integration & Output

  • ZIP Media Pack Export
  • Multi-platform Broadcast (Instagram/LinkedIn/Twitter)
  • CSV/Print Report Export
  • SMTP Email Notifications
  • Session: Database Driver
  • Cache: Database Driver
  • File Storage: Local (public/uploads)
