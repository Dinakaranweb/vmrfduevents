VMRF(DU) Activity Workflow

Simplified End-to-End Approval Process

1. Activity Submission
College Admin
User logs the event details, applies AI templates, and attaches mandatory photos.
Status: pending
2. Institutional Verification
Registrar
Registrar reviews the submission for academic compliance.
If Approved: Proceeds to Media Studio
↺ If Discuss: Returned to College Admin for corrections
3. Media Studio Enhancement
Media Editor
Editor crops photos, generates AI social captions, and submits to the executive office.
🔒 RECORD LOCKED
4. Executive Review
Office of Registrar
Final authorization of the media package before broadcast.
If Approved: Ready for Publication
↺ If Discuss: Unlocked & returned to Media Editor
5. Broadcast & Archive
Editor / Admin
Activity is published to the University portal and official social media channels.
✓ Status: published
